# SelfGuide 模块

模块表示做什么，server／local 表示浏览器在哪里；两种浏览器版本使用相同的模块结构。

| 模块 | 状态 | 入口 |
| --- | --- | --- |
| 写作 | 已启用 | [写作模块](writing.md) |
| 绘图 | 预留，暂空 | [绘图模块](drawing.md) |
| 实验迭代 | 预留，暂空 | [实验迭代模块](experiments.md) |

用户可以直接说“用 SelfGuide 的写作模块……”。涉及文章起草、修改、翻译或润色时读取写作模块。写作由网页端主导，Codex 按需补充材料并保存、排版。绘图和实验迭代目前只有空位，没有专用流程，不将它们描述成已实现的功能。

共同的项目、登录、文本交接和任务恢复机制仍由主 SKILL.md 管理。模块不各自新建 skill 或账户。
