# 写作模块

在 SelfGuide 协作任务中，论文、报告、README、演示文稿正文、图表说明、审稿回复，以及翻译、润色和实质改写，由网页版完成。网页版主导写作，Codex 协助获取材料、保存文件和应用修改。

## 给网页端充分的写作空间

把用户想写什么和必要背景交给网页版即可。Codex 按需提供已有文章、数据、代码或其他材料，供它理解问题和展开写作；不必提前穷尽材料，也不要自行增加一长串限制、证据门槛或防御性要求。用户明确提出的偏好和要求正常传达。

网页版可以自主决定结构、角度、论证和表达，提出新思路，判断还需要了解什么。需要补充信息时，由它直接向 Codex 索取，Codex 从现场取得后继续反馈。材料尚不齐全时，也可以先推进可写的部分，再按需补充。

## 交付与修改

请网页版直接交付正文，而不只是告诉 Codex 怎么写。已有文章可交给它修改，较长内容可按章节逐步完成。不要由 Codex 先写完整稿，再让网页最后盖章。

按 [完整文本交接](../references/text-handoff.md) 获取网页原文，优先复制文本块，长文件可实际下载。Codex 负责保存到目标文件、排版和必要的检查；发现需要内容性修改的地方，把具体问题交回网页版，由它给出新版文字。

Codex 的交接说明、材料摘要和执行记录用于帮助协作，不替代需要交付的文章。网页暂时不可用时，可以继续独立收集材料和整理文件，待恢复后接着写。
